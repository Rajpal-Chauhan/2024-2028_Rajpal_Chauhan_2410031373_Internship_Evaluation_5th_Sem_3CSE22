## 📌 About the Internship

The Web Development internship at **Thiranex EduTech LLP** followed a structured, task-based learning programme. It covered five areas of web development, progressing from semantic HTML5 and accessibility to responsive CSS design, JavaScript application logic, asynchronous API integration, and project architecture and deployment concepts.

The five tasks were presented through an internship task dashboard. Each of the five supplied task cards is marked **Completed Successfully**. The task descriptions and expected outcomes are summarized in this repository.

---

## 🎯 Objectives

- Understand semantic HTML5 structure and web accessibility practices.
- Build a multi-page personal portfolio website.
- Create responsive layouts using CSS Grid, Flexbox, and media queries.
- Understand JavaScript DOM manipulation, event handling, and state management.
- Develop a client-side To-Do List application with CRUD functionality.
- Use Local Storage to retain task data across browser reloads.
- Retrieve and process JSON data from a public REST API.
- Understand asynchronous JavaScript using Fetch API and `async/await`.
- Learn the concepts of modular frontend architecture and client-side routing.
- Understand asset optimization and modern web application deployment.

## 🚀 Internship Tasks

### 1. HTML5 Semantic Structure & Accessibility

**Objective:** Build a multi-page personal portfolio website using modern semantic HTML5 standards and accessibility guidelines.

**Key Areas:**
- Semantic HTML5 page structure
- ARIA labels and roles for assistive technologies
- Screen-reader accessibility considerations
- SEO-friendly metadata
- Accessible, keyboard-navigable contact form

**Expected Outcome:** A semantic portfolio website structure designed with accessibility and search-engine optimization in mind.

**Dashboard Due Date:** 21 September 2026  
**Status:** Completed

---

### 2. Advanced CSS3 & Responsive Architecture

**Objective:** Transform the portfolio structure into a visually organized, fully responsive website.

**Key Areas:**
- CSS Grid for two-dimensional page layouts
- Flexbox for component alignment
- Mobile-first responsive media queries
- CSS variables
- Light and dark theme support

**Expected Outcome:** A responsive website layout designed to adapt to mobile, tablet, and desktop screen sizes.

**Dashboard Due Date:** 28 September 2026  
**Status:** Completed

---

### 3. JavaScript Logic & State Management

**Objective:** Develop an interactive, client-side To-Do List application to practise DOM manipulation, event handling, and browser data persistence.

**Key Features:**
- Create, Read, Update, and Delete (CRUD) functionality
- Dynamic DOM manipulation
- Event handling and delegated event listeners
- Local Storage for data persistence
- All, Active, and Completed task filters

**Expected Outcome:** A task-management application designed to retain user data across browser reloads.

**Dashboard Due Date:** 05 October 2026  
**Status:** Completed

---

### 4. Asynchronous JavaScript & RESTful APIs

**Objective:** Build a Weather Dashboard by fetching and processing JSON data from a public REST API using asynchronous JavaScript.

**Key Features:**
- Fetch API
- `async/await`
- JSON response processing, including nested objects
- Error handling for failed network requests
- Dynamic rendering of weather information
- City-name search functionality

**Expected Outcome:** A dashboard designed to display weather information such as temperature, humidity, and wind speed based on user input.

**Dashboard Due Date:** 12 October 2026  
**Status:** Completed

---

### 5. Full-Stack Deployment & Project Architecture

**Objective:** Combine the earlier learning areas to plan, optimize, and deploy a comprehensive Web Development capstone application. The task description gives an e-commerce product catalogue as an example.

**Key Areas:**
- Modular frontend application architecture
- Client-side routing
- Asset optimization
- Image optimization and code minification
- Deployment platforms such as Vercel, Netlify, or Render

**Expected Outcome:** A production-ready web application with a public URL.

**Dashboard Due Date:** 14 October 2026  
**Status:** Completed

> **Note:** The supplied task description gives an e-commerce product catalogue as an example. It does not identify the exact capstone project selected or provide a deployment URL. Add those details only if they match the project you actually completed.

## 🔄 Development Methodology

The internship tasks can be understood through the following workflow:

1. **Requirement Understanding** – Review the purpose, features, and expected outcome of each task.
2. **Structure Planning** – Organize the page content and application components.
3. **Frontend Development** – Use HTML5 and CSS3 to create the page structure and visual layout.
4. **Responsive Design** – Apply Grid, Flexbox, and media queries to support different screen sizes.
5. **JavaScript Functionality** – Add DOM manipulation, event handling, and application logic.
6. **Data Persistence** – Use Local Storage to retain task information in the browser.
7. **API Integration** – Retrieve and process external data using Fetch API and asynchronous JavaScript.
8. **Error Handling** – Handle failed network requests and process API responses.
9. **Architecture Planning** – Understand modular application structure and client-side routing.
10. **Deployment Preparation** – Consider asset optimization and deployment platforms.
