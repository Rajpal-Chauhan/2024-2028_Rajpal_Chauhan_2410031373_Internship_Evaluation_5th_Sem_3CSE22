## 📌 About the Internship

The internship at **Thiranex EduTech LLP** focused on practical learning
in Web Development through a structured sequence of five tasks. The
tasks covered the fundamentals of building and improving web
applications, beginning with semantic HTML5 and accessibility, followed
by responsive CSS design, JavaScript application logic, asynchronous API
integration, and project architecture and deployment concepts.

The internship tasks were organized to provide exposure to different
stages of the web development workflow. The supplied task dashboard
shows all five listed tasks with a **Completed Successfully** status.

## 🚀 Internship Tasks

### 1. HTML5 Semantic Structure & Accessibility

A task focused on building a multi-page personal portfolio website using
semantic HTML5 standards and accessibility guidelines.

**Key Areas:** - Semantic HTML5 page structure - ARIA labels and roles -
Screen-reader accessibility considerations - SEO-friendly metadata -
Accessible and keyboard-navigable contact form

**Expected Outcome:** A semantic portfolio website structure designed
with accessibility and search-engine optimization in mind.

------------------------------------------------------------------------

### 2. Advanced CSS3 & Responsive Architecture

A task focused on transforming the portfolio structure into a visually
organized and responsive website.

**Key Areas:** - CSS Grid for two-dimensional layouts - Flexbox for
component alignment - Mobile-first responsive media queries - CSS
variables - Light and dark theme support

**Expected Outcome:** A responsive website layout designed to adapt to
mobile, tablet, and desktop screen sizes.

------------------------------------------------------------------------

### 3. JavaScript Logic & State Management

A task focused on developing an interactive client-side To-Do List
application to understand DOM manipulation, event handling, and browser
data persistence.

**Key Features:** - Create, Read, Update, and Delete (CRUD)
functionality - Dynamic DOM manipulation - Event handling and delegated
event listeners - Local Storage for data persistence - All, Active, and
Completed task filters

**Expected Outcome:** A task-management application designed to retain
task data across browser reloads.

------------------------------------------------------------------------

### 4. Asynchronous JavaScript & RESTful APIs

A task focused on building a Weather Dashboard by fetching and
processing JSON data from a public REST API using asynchronous
JavaScript.

**Key Features:** - Fetch API - Async/await - JSON response processing -
Error handling for failed network requests - Dynamic rendering of
weather information - City-name search functionality

**Expected Outcome:** A dashboard designed to display weather
information such as temperature, humidity, and wind speed based on user
input.

------------------------------------------------------------------------

### 5. Full-Stack Deployment & Project Architecture

A task focused on combining the earlier learning areas to plan,
optimize, and deploy a comprehensive Web Development capstone
application. The task description gives an e-commerce product catalogue
as an example.

**Key Areas:** - Modular frontend application architecture - Client-side
routing - Asset optimization - Image optimization and code
minification - Deployment platforms such as Vercel, Netlify, or Render

**Expected Outcome:** A production-ready web application with a public
URL. The supplied task description does not identify a specific selected
capstone project or provide its deployment URL.
